# Assistente de Voz Acessível (JW.ORG & Web)

Aplicativo acessível por comando de voz contínuo projetado para pessoas cegas lerem a reunião da semana, A Sentinela, textos da Bíblia e o Texto Diário diretamente do `jw.org`, além de navegar na internet usando **Google Gemini** + **FastAPI** + **Playwright**.
